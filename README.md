# Retaining Walls Builders

React, TypeScript and Vite website for Retaining Walls Builders in Greater Sydney, New South Wales, Australia.

## Commands

- `npm run dev` starts the local Vite server.
- `npm run build` validates content and navigation, generates the sitemap, builds the client bundle, prerenders all public routes and verifies the final `dist` output.
- `npm run preview` serves the production build locally.

Content is managed through typed data files in `src/data/services`, `src/data/locations`, `src/data/blog` and `src/data/business.ts`.
